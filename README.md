# Yaseen Almahayshi — Portfolio

Personal portfolio for a backend-focused software engineer working across APIs, integrations, data workflows, and modular business systems.

The site is built with React, TypeScript, and Vite. It includes selected work, professional and academic CV views, accessible navigation, print styling, metadata, and direct-route support for GitHub Pages.

## Local development

```bash
pnpm install
pnpm dev
```

Run `pnpm typecheck` and `pnpm build` before publishing. Pushes to `main` are deployed through the GitHub Pages workflow.

Company work is described only within explicit public-information boundaries. This repository does not contain private company source code, customer information, operating data, or internal documentation.
